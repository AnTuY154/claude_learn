# Domain 5 — Six offline Build Exercises

**Only content authority:** https://claudecertificationguide.com/learn/5-context-management

Each lesson includes five practical steps in the bilingual website and a deterministic Node.js fixture that does **not** call Claude API or pretend to be actual model output.

| Lesson | Practice and executable check |
|---|---|
| 5.1 | Persistent facts, summarisation boundary and tool-result trimming |
| 5.2 | Three escalation triggers, frustration exception and identity ambiguity |
| 5.3 | Structured transient failure, valid empty results and partial findings |
| 5.4 | Scratchpad of exact code evidence and crash-recovery state manifest |
| 5.5 | Document-field accuracy segments and wrong high-confidence extractions |
| 5.6 | Five-part claim-source mappings and conflicting sourced values |

Run `npm run lab:domain5 -- 1` through `6`. Open `domain5-workspaces/lesson5N`, inspect and edit `fixture.json`, then run `node check.mjs`. The program refuses to overwrite existing student work and the directory is gitignored. These checks are teaching fixtures only; they are not measurements of Claude model reliability.

To review all five domains by the single trusted source, run the existing opt-in CCAR-F Source-Only Curriculum Review GitHub workflow with input `all` (30 lessons; API fees and credential setup required), or `5.1`.. `5.6` for a single lesson.
